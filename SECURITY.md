# Reporting a Vulnerability

To report a vulnerability, please open a private vulnerability report at https://github.com/rollup/rollup/security.

While the discovery of new vulnerabilities is rare, we also recommend always using the latest versions of Rollup and its official plugins to ensure your application remains as secure as possible.

Note that code generated by Rollup trusts the document it runs in. In particular, when `amd`, `iife`, `umd` or CommonJS output runs in a browser, `import.meta.url` and emitted file URLs depend on the document base URL at runtime. Attacks that rely on injecting `<base>` elements into a page are therefore the responsibility of the embedding application. See [File URLs](https://rollupjs.org/plugin-development/#file-urls) for details and mitigations.

# Canonical license texts

`npm run build:rust-licenses` uses these texts for crates that declare a license but do not ship its text. Only licenses that do not carry a per-crate copyright notice are supported here; crates that need their own copyright line are covered by `rust/license-overrides/` instead.

| File             | License    |
| ---------------- | ---------- |
| `apache-2.0.txt` | Apache-2.0 |
